# hosh — عامل واکنشی ساده جاروبرقی (محیط ۲×۲)

کد یک **عامل واکنشی ساده (Simple Reflex Agent)** برای مسئله کلاسیک جاروبرقی در محیط ۲×۲.

## مراحل الگوریتم

1. **ادراک:** خواندن وضعیت خانه فعلی (`dirty` یا `clean`).
2. **تطابق با قوانین:** اگر کثیف است ⟶ عمل `CLEAN`؛ اگر تمیز است ⟶ حرکت به سمت خانه بعدی مسیر ثابت.
3. **اجرا:** اجرای عمل انتخابی در محیط.
4. **تکرار:** تا زمانی که همه خانه‌ها تمیز شوند.

مسیر بازدید: `(0,0) → (0,1) → (1,1) → (1,0)`

> یک عامل واکنشی کاملاً بدون حافظه در محیط ۲×۲ می‌تواند در حلقه بیفتد؛ بنابراین یک حالت داخلی حداقلی (موقعیت + خانه‌های بازدیدشده) اضافه شده است.

## اجرا

```bash
python vacuum_reactive.py
```
